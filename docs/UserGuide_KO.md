# 니켈체크 사용 설명서 (앱 0.9.0)

안드로이드 휴대폰에 측정기를 USB로 연결해 니켈 도금액 농도를 재고 기록하는 앱입니다.

이 앱은 시제품입니다. 화면에 나오는 농도는 측정기에 저장된 검량식으로 계산한 값이며, 측정 정확도와 현장 적용은 따로 검증해야 합니다. 제품 합격 여부나 약품 보충량을 판단하지 않습니다.

## 1. 준비물

| 준비물 | 조건 |
|---|---|
| 휴대폰 | 안드로이드 8.0 이상, USB 기기 연결(USB 호스트) 지원. 아이폰은 쓸 수 없습니다 |
| 측정기 | ESP32 + AS7341, 팀 최종 `nickel_rig` 펌웨어(한국어 텍스트 통신) |
| 케이블 | 데이터가 되는 USB 케이블. 단자가 맞지 않으면 OTG 어댑터 |
| 큐벳 | 증류수용 1개, 시료용 |

측정기 안의 센서 배선은 3V3–VIN, GND–GND, GPIO21–SDA, GPIO22–SCL입니다.

## 2. 설치

1. APK 파일(`NiCheck_v0.9.0_....apk`)을 휴대폰으로 보냅니다.
2. 휴대폰에서 파일을 누릅니다.
3. "출처를 알 수 없는 앱 설치"를 허용하고 설치합니다.

새 버전이 나오면 새 APK를 그대로 설치합니다. 기록은 남습니다. 다만 파일 이름에 `test`가 들어간 시험용 빌드가 깔려 있으면 먼저 지워야 하고, 그때 기록도 지워집니다. 지우기 전에 CSV로 내보내세요.

## 3. 측정 순서

1. **연결**: 앱을 열면 시작 화면이 나옵니다. 측정기를 케이블로 휴대폰에 꽂습니다. USB 접근 권한을 묻는 창이 뜨면 허용합니다. **USB 장비 연결**을 누르면 측정 화면으로 바뀝니다.
2. **영점**: 증류수 큐벳을 넣고 뚜껑을 닫습니다. "용기를 고정하고 외부 빛을 가렸습니다."에 체크하고 **증류수 영점 측정**을 누릅니다.
3. **측정**: 시료 큐벳으로 바꿉니다. 작업자와 측정 이름을 적고, 다시 체크한 뒤 **측정하고 자동 저장**을 누릅니다.
4. **결과**: 농도(g/L)와 기준 대비 %, 판정이 나오고, 기록이 자동으로 저장됩니다.
5. **다시 채워 한 번 더**: 큐벳을 비우고 같은 시료를 다시 채운 뒤 **같은 시료 다시 채워 측정**을 누릅니다. 화면의 큰 숫자, 기준 대비 %, 판정이 평균으로 바뀝니다. 평균이 최종값입니다. 기록의 농도 칸에는 그 회차에 잰 값이 남습니다.

- 시작 화면과 관리 화면의 **사용 방법**을 누르면 이 순서를 앱 안에서 볼 수 있습니다.
- 측정 이름이나 시료 ID를 바꾼 뒤에는 **같은 시료 다시 채워 측정**이 되지 않습니다. 다른 시료와 평균되는 것을 막기 위해서입니다.
- 두 번 잰 값의 차이가 0.1 g/L을 넘으면 한 번 더 채워 재라는 안내가 나옵니다. 채울 때마다 기포나 부유물이 달라지기 때문입니다.
- 다른 시료로 넘어갈 때는 **측정하고 자동 저장**을 누릅니다. 채움 비교가 새로 시작됩니다.
- 체크 표시는 측정할 때마다 다시 해야 합니다.
- 영점을 잰 지 5분이 지나면 측정 전에 "영점 확인" 창이 뜹니다. LED 밝기가 시간에 따라 변하기 때문입니다. **취소**를 누르고 증류수 영점을 다시 잰 뒤 측정하는 것이 좋습니다. **확인**을 누르면 그대로 잽니다.
- 연결했을 때 측정기에 영점이 남아 있어도 언제 잰 것인지 알 수 없어서, 영점을 다시 잴 때까지 같은 창이 뜹니다.
- 영점을 잰 시각은 측정 화면 아래 "측정기 상태"에 나옵니다. 측정기의 버튼으로 영점을 재면 앱은 그 시각을 알지 못합니다.
- 영점을 다시 재거나 게인을 바꿔도 검량식은 그대로 유지됩니다.

### 판정

| 판정 | 뜻 |
|---|---|
| 정상 | 농도가 설정한 범위 안에 있습니다 |
| 경고 · 낮음 / 경고 · 높음 | 농도가 하한보다 낮거나 상한보다 높습니다 |
| 검량 범위 모름 | 검량식을 어떤 농도 범위에서 만들었는지 앱이 모릅니다. 농도는 표시되지만 "정상"이라고 하지 않습니다. 관리 화면에서 검량 범위를 입력하면 풀립니다 |
| 확인 필요 | 520 흡광도가 ±0.05를 넘었습니다. 농도는 표시되지만 믿기 전에 확인해야 합니다 |

- 하한의 기본값은 4.2 g/L입니다. 회사가 이 농도 아래에서 작업을 중단한다고 답한 값입니다. 상한은 아직 확정되지 않아 비어 있습니다.
- **확인 필요**가 나오면 다시 채워서 잽니다. 그래도 같으면 적정으로 확인합니다. 520 흡광도가 높으면 탁도·기포·큐벳 오염을, 음수이면 증류수 영점을 의심합니다.
- 판정은 농도 범위와 520 신호만 봅니다. 제품 합격 여부를 판단하는 것이 아닙니다.

## 4. 시료 정보와 적정 결과 (선택)

- **시료 정보 입력**을 누르면 시료 ID, 공장, 라인, 도금조, 시료 온도, MTO, 채취 시각을 적을 수 있습니다. 공장·라인·도금조는 다음에도 남아 있습니다. 시료 ID, 온도, MTO, 채취 시각, 기준 농도는 농도가 나온 뒤 비워집니다. 다음 시료 기록에 앞 시료의 정보가 붙지 않게 하려는 것입니다. 다시 채워 잴 때는 처음 적은 정보가 그대로 기록됩니다.
- 표준액은 같은 농도를 여러 번 재기 때문에 표준액 체크와 농도가 남아 있습니다. 측정 이름만 바꾸고 그대로 재려 하면 표준액으로 기록할지 한 번 묻습니다.
- 적정으로 구한 농도가 있으면 "기준 농도 g/L" 칸에 적습니다. 기록에 함께 저장됩니다. 측정할 때만 넣을 수 있고 나중에 추가할 수는 없습니다.

## 5. 기록과 CSV

- **기록** 탭에 최근 측정 40건이 보입니다. 기록은 휴대폰 안에만 저장되고 서버로 보내지 않습니다.
- **CSV 파일로 내보내기**를 누르면 전체 기록을 파일로 저장합니다(31개 열). 엑셀에서 열 수 있습니다.
- 앱을 지우면 기록도 지워집니다. 지우기 전에 CSV로 내보내세요.

## 6. 관리 화면

| 항목 | 설명 |
|---|---|
| 장비 상태 | 센서, 게인, 영점, 검량식(m, c)과 검량식의 출처를 보여 줍니다 |
| 기준값 설정 | 기준 농도(100%에 해당, 기본 5.2 g/L)와 범위 하한·상한. 하한 기본값은 4.2 g/L, 상한은 비어 있습니다. 둘 다 비우면 범위 판정을 하지 않습니다 |
| 검량선 관리 | 앱에서 검량할 때 씁니다. 아래 "검량" 참고 |
| 게인 설정 | 바꾸면 영점이 지워집니다. 바꾼 뒤 증류수 영점을 다시 잽니다 |

### 검량

검량식은 측정기 안에 저장됩니다. PC 프로그램에서 저장한 검량식이 있으면 앱은 그것을 그대로 씁니다. 이 경우 결과 아래에 "검량 범위를 모릅니다"라고 나옵니다. 어떤 농도의 표준액으로 만든 식인지 앱이 알 수 없다는 뜻입니다. 이때는 판정이 "정상"으로 나오지 않습니다.

관리 화면의 **검량 범위**에 그 검량식을 만든 표준액의 가장 낮은 농도와 높은 농도를 적고 **검량 범위 저장**을 누릅니다. 그 뒤로는 범위 밖의 값을 "검량 범위 밖"으로 보류합니다. 입력한 범위에는 여유를 두지 않습니다. 측정기의 검량식(m, c)이 바뀌면 입력한 범위는 쓰이지 않으니 다시 입력합니다.

앱에서 직접 검량하려면:

1. 증류수 영점을 잽니다.
2. 농도를 아는 표준액 3종 이상을 각각 3회 이상 잽니다. 잴 때마다 "기준 농도 g/L"에 그 농도를 적고 "기준 농도가 확인된 검량용 표준액"에 체크합니다.
3. 관리 화면에서 **검량선 검토 후 측정기에 저장**을 누릅니다. R²가 0.995보다 낮으면 저장되지 않습니다.

앱에서 저장하면 측정기에 있던 검량식을 덮어씁니다. 앱에서 검량한 뒤에는 표준액 농도 범위를 0.2 g/L 넘게 벗어난 측정값을 "검량 범위 밖"으로 보류합니다.

## 7. 안내 문구와 대처

농도 대신 "농도 결과 보류"가 나오면 아래 문구를 확인합니다. 보류된 측정도 원본 신호와 함께 기록에 남습니다.

| 문구 | 대처 |
|---|---|
| 측정기에 다른 펌웨어가 들어 있습니다 | 측정기에 팀 최종 `nickel_rig` 펌웨어를 설치합니다. PC 프로그램의 펌웨어 설치 기능을 씁니다 |
| 센서 응답이 없습니다 | 센서 선(SDA 21 / SCL 22)과 전원을 확인합니다 |
| 측정기가 답하지 않습니다 | 케이블이 데이터용인지, 측정기에 전원이 들어오는지 확인합니다 |
| 영점이 없습니다 | 증류수 영점을 잽니다 |
| 영점을 잰 지 N분 지났습니다 / 언제 잰 것인지 알 수 없습니다 | 취소를 누르고 증류수 영점을 다시 잽니다. 확인을 누르면 그대로 잽니다 |
| 검량식이 없습니다 | PC 프로그램이나 앱에서 검량합니다 |
| 검량 범위 밖입니다 | 적정 등 기준 분석으로 확인합니다 |
| 채움 간 차이가 0.1 g/L을 넘습니다 | 큐벳을 비우고 다시 채워 한 번 더 잽니다 |
| 빛이 너무 강합니다 | 관리 화면에서 게인을 낮추고 영점을 다시 잽니다 |
| 빛이 너무 약합니다 | LED, 큐벳, 센서의 위치와 뚜껑을 확인합니다 |
| 520 흡광도가 높습니다 | 큐벳 오염, 기포, 탁도를 확인하고 다시 채워 잽니다. 농도는 표시되고 판정은 "확인 필요"입니다 |
| 520 흡광도가 음수입니다 | 증류수 영점을 다시 잽니다. 판정은 "확인 필요"입니다 |
| 측정기가 보낸 농도와 검량식이 맞지 않습니다 | 관리 화면에서 장비 상태를 새로고침하고 다시 잽니다 |
